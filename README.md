# ESP32 Examples for Physics Education

This repository contains ESP32 source codes used in experiments, demonstrations, and educational projects presented on the **Piláth Blog**.

The programs were developed primarily for physics and STEM education. Most examples accompany practical experiments described in detail on the blog.
Not every project contains all of these files. Some directories contain only the ESP32 source code when the complete description is available on the blog.


## Educational use

These programs were created primarily as teaching and experimental tools rather than as production software.

They are intended to make it easier to reproduce experiments, modify the measurement setup, and explore how microcontrollers can be used in physics education.

Students and teachers are encouraged to modify the programs and adapt them to their own experiments.

The programs in this repository were developed over several years for different experiments and hardware configurations. Therefore, coding style and library versions may vary between projects.

Some older examples are preserved in their original form because they correspond directly to the versions used in the associated experiments and blog articles.
